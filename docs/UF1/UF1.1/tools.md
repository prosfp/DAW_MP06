# Eines de programació

Existeixen diverses eines de programació que ens ajuden a desenvolupar aplicacions web. Aquestes eines poden ser editors de text, entorns de desenvolupament integrats (IDE) o eines de control de versions com Git.

En aquesta secció, explorarem algunes de les eines més populars i útils per a desenvolupar aplicacions web. Tot i així, per poder-ho tenir més accessible, hem creat una secció específica a l'arrel d'aquesta wiki. Podràs accedir-hi a través de l'apartat de [Tooling](/#Tooling).
